# Расписание → Google Calendar

Скрипт для автоматического импорта расписания из **Google Таблиц** в **Google Calendar**.

Проект рассчитан на расписание, которое хранится в **Яндекс Таблицах**. Чтобы использовать его, достаточно сохранить таблицу из Яндекса в формате `.xlsx`, импортировать её в Google Таблицы и запустить скрипт.

После импорта расписания занятия автоматически создаются в Google Calendar с учетом курса и группы.

## Возможности

* Импорт расписания из Google Таблиц в Google Calendar.
* Выбор курса и учебной группы.
* Автоматическое создание событий календаря.
* Добавление аудитории отдельно в описание события.
* Удаление ранее импортированных событий.
* Работа с расписанием, перенесённым из Яндекс Таблиц через `.xlsx`.

## Как это работает

Общий процесс выглядит следующим образом:

```text
Яндекс Таблицы
      ↓
Сохранить как .xlsx
      ↓
Импортировать в Google Таблицы
      ↓
Установить Apps Script
      ↓
Выбрать курс и группу
      ↓
Импортировать расписание
      ↓
Google Calendar
```

## Установка

### 1. Подготовьте расписание

Если расписание находится в Яндекс Таблицах:

1. Откройте таблицу с расписанием.
2. Сохраните или скачайте её в формате `.xlsx`.
3. Создайте новую Google Таблицу.
4. Импортируйте в неё полученный `.xlsx` файл.

После импорта структура таблицы должна соответствовать той, для которой предназначен скрипт.

### 2. Откройте Apps Script

В Google Таблице откройте:

**Расширения → Apps Script**

Откроется редактор Google Apps Script.

В проекте уже будет файл:

```text
Code.gs
```

Удалите содержимое этого файла и вставьте в него код из файла `Code.gs` из репозитория.

### 3. Добавьте HTML-файл

В редакторе Apps Script слева нажмите:

**+ → HTML**

Создайте файл с названием:

```text
GroupDialog
```

В него вставьте содержимое файла:

```text
GroupDialog.html
```

> **Важно:** названия файлов должны точно совпадать с названиями файлов в репозитории. В частности, файл `GroupDialog.html` должен быть создан именно как HTML-файл с именем `GroupDialog`.

В итоге структура проекта должна выглядеть примерно так:

```text
Code.gs
GroupDialog.html
```

### 4. Сохраните проект

Нажмите **Сохранить** в Apps Script.

После сохранения вернитесь в Google Таблицу и **полностью перезагрузите страницу**.

После перезагрузки в верхнем меню должна появиться новая вкладка:

**Расписание**

В ней будут доступны команды:

* **Импортировать расписание**
* **Удалить импортированные события**

## Первый запуск

Для импорта расписания:

1. Откройте меню **Расписание**.
2. Выберите **Импортировать расписание**.
3. Выберите необходимые курс и учебную группу.
4. Подтвердите импорт.

После выполнения скрипта занятия из таблицы будут добавлены в Google Calendar.

## Удаление расписания

Если необходимо удалить ранее импортированные события:

**Расписание → Удалить импортированные события**

Используйте эту функцию, например, если расписание было импортировано повторно или требуется очистить календарь перед новым импортом.

## Важное ограничение

Для занятий по английскому скрипт просто записывает в какой день он будет, для него смотрите отдельно свое расписание.

## Требования

Для работы проекта необходимы:

* Google аккаунт;
* Google Таблицы;
* Google Calendar;
* доступ к Google Apps Script;
* исходная таблица с расписанием;
* если расписание находится в Яндекс Таблицах — возможность экспортировать его в `.xlsx`.

## Структура репозитория

```text

```

`Code.gs` — основной код Google Apps Script.

`GroupDialog.html` — HTML-интерфейс для выбора курса и группы.

`README.md` — инструкция по установке и использованию проекта.
